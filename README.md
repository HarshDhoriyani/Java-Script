# 📘 Learning JavaScript

Welcome to my JavaScript learning journey! 

This repository documents the topics I’m exploring as I learn one of the most powerful and widely used programming languages for web development — **JavaScript**.

---

## 📌 Why JavaScript?

JavaScript is a versatile, high-level programming language that powers the **interactive behavior of websites**. It’s essential for **frontend development**, widely used in **backend development** (Node.js), and plays a key role in building **modern web applications**.

---

## 📚 Topics Covered

Below is the list of JavaScript concepts and topics I'm learning, categorized for better understanding:

### 🟢 Basics
- Introduction to JavaScript
- Setup (VS Code, Browser Console)
- Comments
- Variables (`var`, `let`, `const`)
- Data Types (Number, String, Boolean, Null, Undefined, Symbol, BigInt)
- Type Conversion & Coercion

### 🔁 Operators & Control Flow
- Arithmetic, Comparison, Logical Operators
- Conditional Statements (`if`, `else`, `switch`)
- Loops (`for`, `while`, `do-while`)
- Break & Continue

### 📦 Functions
- Function Declaration & Expression
- Arrow Functions
- Parameters vs Arguments
- Return Values
- Callback Functions
- IIFE (Immediately Invoked Function Expressions)

### 🧱 Objects & Arrays
- Objects (Creation, Properties, Methods)
- Dot vs Bracket Notation
- Array Methods (`push`, `pop`, `shift`, `unshift`, `splice`, etc.)
- Iterating Arrays (`forEach`, `map`, `filter`, `reduce`)
- Destructuring (Arrays & Objects)
- Spread and Rest Operators

### 🔤 Strings & Numbers
- String Methods (`length`, `slice`, `replace`, `toUpperCase`, etc.)
- Template Literals
- Number Methods and `Math` Object

### 🧮 Advanced Concepts
- Scope & Lexical Environment
- Closures
- Hoisting
- The `this` Keyword
- Bind, Call, Apply
- Prototypes and Inheritance
- ES6+ Features (let/const, arrow functions, destructuring, template literals, etc.)

### ⛓️ Asynchronous JavaScript
- Callbacks
- Promises
- `async` / `await`
- `fetch` API
- Error Handling (`try`, `catch`)

### 🌐 DOM Manipulation
- Selecting Elements (`getElementById`, `querySelector`, etc.)
- Modifying Text & Styles
- Adding/Removing Elements
- Event Handling (click, input, etc.)
- Event Delegation

### 📦 Browser APIs
- Local Storage / Session Storage
- Web APIs (`fetch`, `setTimeout`, `setInterval`)
- Geolocation API
- History & Navigator

### 🧪 Debugging & Tools
- Console Methods (`log`, `warn`, `error`, `table`)
- DevTools
- Linting (ESLint)
- Writing Clean Code
